# MeristemForge 官网

[English](README.md)

MeristemForge 是一体化本地 AI 创作工作台，覆盖视频创作、图片创作、音乐创作，以及 AI 配音与音色克隆。本仓库包含其官方产品网站。

Windows 公开版本正在准备中，当前网站不提供安装包下载。

## 本地开发

```powershell
cd frontend
npm install
npm run dev
```

打开 http://localhost:3000。

## 验证

```powershell
npm run test -- --run
npm run build
```

## 技术栈

- Vue 3
- TypeScript
- Vite
- Vue I18n
