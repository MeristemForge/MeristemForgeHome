# MeristemForge 官网透明导航与首屏设计

## 已确认的方向

采用布局预览中的 B 版：保留小鸭子及全页青蓝—紫粉渐变；MeristemForge 图标和名称仍位于导航左侧；首屏文案与顶部导航不再放在两块深色面板内。主体文字保持白色，用柔和的深蓝阴影帮助浅蓝区域上的阅读。顶部导航只在页首出现，并随页面滚动离开画面。

## 范围与边界

- 顶部导航的整体容器去掉背景色、边框、圆角框感、投影和背景模糊；品牌、锚点链接、语言切换和 Windows 状态按钮保持原有功能，并参与页面正常排版。
- 首屏文案容器去掉背景色、边框、圆角框感、投影和背景模糊；通过文字块间距维持标题、说明和按钮的层次，不让文案贴近页面边缘。
- 品牌名称、导航链接、首屏眉题、标题及说明文字为白色，并采用克制的深蓝文字阴影。阴影只作用于文字，不形成新的整块背景。若渐变某处的文字仍难读，优先微调文字阴影与排布；不能以恢复深色面板作为未经确认的替代方案。
- Windows 状态按钮、语言切换按钮和“查看创作能力”按钮仍可使用各自的小面积按钮底色及边界，以清楚区分可操作元素和不可下载状态。导航链接的局部悬停或键盘焦点状态也保留。
- 在所有宽度下，导航均只出现在页面顶部，向下滚动后不悬浮在内容上。手机端品牌与语言切换位于第一行，三个锚点链接位于第二行；原有底部悬浮导航移除。
- 导航不再遮盖锚点目标，章节的锚点顶部留白相应缩小；手机页脚也不再为底部悬浮条预留多余空白。
- 小鸭子的透明图片、光晕、浮动效果，四张创作卡片，以及其他章节布局均不在本次改动范围。
- 安装包下载是另一个发布任务；在公开 Release 和安装包存在前，网站的 Windows 状态按钮继续禁用，不连接失效链接。

## 实现位置

主要调整 `frontend/src/assets/main.css` 中的 `.navbar__inner`、导航文字相关选择器、`.hero__copy`、首屏文字相关选择器及对应响应式规则。`Navbar.vue` 和 `HeroSection.vue` 的结构、中文和英文文案不需要改变；若视觉验证发现布局需要少量结构调整，再限定在这两个组件内。

该改动不增加接口、状态或数据流。语言切换、锚点跳转和下载状态保持现有逻辑；没有新增错误处理路径。

## 验收

1. 在首屏能直接看见贯通的渐变，导航和主文案没有深色矩形背景；品牌位于导航左侧，导航随滚动离开画面。
2. 页首的品牌、导航链接和首屏白字仍容易辨认；文字阴影柔和，不变成粗重描边或新面板。向下滚动后内容不被导航遮挡。
3. 在桌面、中等宽度和 320–390px 手机宽度下，导航及首屏不重叠、不裁切；手机端锚点链接位于顶部第二行，底部不再有悬浮导航。
4. 中文、英文切换，锚点跳转，键盘焦点，以及禁用的 Windows 状态按钮行为保持不变。
5. 前端现有自动化测试和生产构建通过；实际浏览器检查首屏、滚动后导航消失及窄屏效果。
